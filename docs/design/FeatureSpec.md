# Feature Spec（要件定義）

## プロジェクト名（仮）

**Civilization Explorer**  
**― AIエージェントが社会を創発し、人間がその法則を探索するプラットフォーム ―**

ハッカソン文脈の検討経緯は [../hackathon/review.md](../hackathon/review.md) を参照。

---

## 背景

AI エージェントによる社会シミュレーションは、「未来を予測する」ためでも、「人間に助言する AI」を作るためでもない。

**社会がどのような法則で成り立つのかを探索するための実験環境**

として利用する。

立場の要約:

* AI 文明そのものが最終目的ではない
* **AI 文明を実験場にして、人間社会の問い（格差・権力・幸福・少数派など）を探る**
* AI が答えを出すのではなく、条件を変えた社会実験を繰り返し、人間が学ぶ

本プロジェクトは、COTEN が目指す「世界史を構造化し、人間の意思決定に活かす」という考え方とも親和的に、

**AI 文明を繰り返し生成し、社会の法則を構造化すること**

を長期的に目指す。

---

## コンセプト

> **What if...? を何万回も試す。**

AI エージェントが自律的に社会を形成する。

人間は

* 初期条件
* 環境
* 制度

だけを変更する。

AI は文明を創る。  
人間は文明を観測する。

---

## ゴール

社会の正解を証明することではない。

目的は

**「どんな条件から、どんな文明が繰り返し生まれるのか」を探索すること。**

シミュレーションは真理の証明ではなく、仮説探索の道具である。

---

## 検証したいテーマ

中心テーマ（[review.md](../hackathon/review.md) より）:

* 格差
* 権力
* 能力差
* 幸福
* 少数派・逸脱者への寛容
* 制度
* 信頼 / 協力
* 資源 / 教育

例となる問い

* 格差は自然発生するのか / 格差のない社会は成立するのか
* 富は権力を生むのか / リーダーは自然発生するのか
* 能力差があっても公平な社会は作れるか
* 少数派に優しい文明はどのような条件で生まれるのか
* 自由と幸福は両立するか
* 何千回の生成で繰り返し現れる制度や価値観はあるのか（長期）

ハッカソン MVP では、上記のうち **1〜2 個の問いがデモで読み取れる** ことを優先する（全問に答える必要はない）。

---

## MVP 機能要件

### 世界

設定可能

* 人口
* 資源
* 教育
* 税率
* 制度
* 初期価値観
* seed（再実行用）

### AI Agent

各 Agent は

* Personality
* Memory
* Goal
* Relationship

を持つ。

LLM が意思決定を行う。

例

* 誰と協力するか
* 誰と争うか
* どこへ移住するか
* 国家へ従うか / 抵抗するか

### シミュレーション

```text
世界生成
  ↓
Agent生成
  ↓
LLM意思決定
  ↓
社会変化
  ↓
文明形成
  ↓
繰り返し（蓄積・再実行）
```

### 可視化

**Three.js の地球儀（世界地図）** で

* Agent（地表の点）
* 集落
* 所属・集団

をリアルタイム表示する。

島国／大陸は実在の舞台（日本・イギリス、東アジア・欧州など）に投影する。衛星写真や建物モデルは使わない（[ADR 0005](../decisions/0005-threejs-world-globe.md)）。

### 構造化・蓄積

文明を構造化して蓄積し、以下を可能にする。

* 過去の文明を比較（MVP は一覧・読込まで。高度な相図 UI は発展）
* 同条件で再実行
* 文明の履歴分析（Event / History / メトリクス）

最低限のエンティティ

* Simulation
* World
* Agent
* Institution
* Event
* History
* Relationship

---

## AI の役割

AI は **文明を構成する主体** である。

* 世界の法則（ルール）だけを人間が設計する
* 人間がルールで「正しい社会」を書き切るのではなく、Agent 同士の相互作用から社会が創発することを目指す
* LLM は意思決定に使い、数値解決・勝敗・資源移動はルール層が行う

---

## 非ゴール（やらないこと）

### ハッカソン評価軸から外れるもの

* AI チャットボット / 人間を直接支援する意思決定 AI
* 業務効率化ツール、便利な UI としての AI 利用だけ
* 「正解」を導く AI

### MVP スコープ外（発展）

* 文明の相図（複数結果の高度な比較分析 UI）
* 数千〜数万回のバッチ大量生成とその自動抽出 UI（ビジョンとしては残す）
* 大規模人口（数百 Agent 以上）でのリアルタイム LLM 意思決定
* 精密な経済・軍事シミュレーション
* 歴史的事実の再現・検証
* 衛星写真・建物モデル・シネマティック 3D 演出

ハッカソンではまず、

1. LLM エージェントが自律的に社会を形成すること
2. その過程を **世界地図（地球儀）**で直感的に観測できること
3. 結果を蓄積し、同条件で再実行できること

を完成させる。

---

## 今回重視するポイント

1. **AI エージェントが主役**であること（LLM が意思決定を担う）
2. **シミュレーションが中心**であり、UI は観測のためのインターフェースであること
3. **文明を構造化して蓄積**し、比較・再実行・分析の土台を作ること
4. **社会の法則を探索する**というテーマを一貫して持つこと（支援 AI に戻らない）
5. 主催側の評価軸（マルチエージェント・創発・人工社会）に沿った見せ方にすること
