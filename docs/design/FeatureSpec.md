# Feature Spec（要件定義）

## プロジェクト名（仮）

**Civilization Explorer**  
**― AIエージェントが社会を創発し、人間がその法則を探索するプラットフォーム ―**

---

## 背景

AIエージェントによる社会シミュレーションは、「未来を予測する」ためではなく、

**社会がどのような法則で成り立つのかを探索するための実験環境**

として利用する。

本プロジェクトは、COTENが目指す「世界史を構造化し、人間の意思決定に活かす」という考え方と同様に、

**AI文明を大量生成し、社会の法則を構造化すること**

を目指す。

---

## コンセプト

> **What if...? を何万回も試す。**

AIエージェントが自律的に社会を形成する。

人間は

* 初期条件
* 環境
* 制度

だけを変更する。

AIは文明を創る。  
人間は文明を観測する。

---

## ゴール

社会の正解を証明することではない。

目的は

**「どんな条件から、どんな文明が繰り返し生まれるのか」を探索すること。**

---

## 検証したいテーマ

* 格差
* 権力
* 信頼
* 協力
* 教育
* 資源
* 幸福
* 制度

例

* 格差は自然発生するのか
* 民主制はどんな条件で維持されるか
* 信頼社会はどう生まれるか
* 富は集中するのか
* AI社会では何が価値になるのか

---

## MVP 機能要件

### 世界

設定可能

* 人口
* 資源
* 教育
* 税率
* 制度
* 初期価値観

### AI Agent

各 Agent は

* Personality
* Memory
* Goal
* Relationship

を持つ。

LLM が意思決定を行う。

例

* 誰と協力するか
* 誰と争うか
* どこへ移住するか
* 国家へ従うか

### シミュレーション

```text
世界生成
  ↓
Agent生成
  ↓
LLM意思決定
  ↓
社会変化
  ↓
文明形成
  ↓
繰り返し
```

### 可視化

**2D マップ**（Canvas 2D または SVG）で

* Agent（円）
* 集落
* 所属・集団

をリアルタイム表示する。

地球の写真・イラスト背景は使わない。薄いグリッド等の抽象平面で、文明の変化を観測する。

Three.js による本格 3D は MVP 外（必要なら後から真上視点のみ検討）。

### 構造化・蓄積

文明を構造化して蓄積し、以下を可能にする。

* 過去の文明を比較
* 同条件で再実行
* 文明の履歴分析

最低限のエンティティ

* Simulation
* World
* Agent
* Institution
* Event
* History
* Relationship

---

## AIの役割

AIは **文明を構成する主体** である。

人間がルールを書くのではなく、AIエージェント同士の相互作用から社会が創発することを目指す。

---

## 非ゴール（MVP外）

* 文明の相図（複数シミュレーション結果の高度な比較分析 UI）
* 大規模人口（数百 Agent 以上）でのリアルタイム LLM 意思決定
* 精密な経済・軍事シミュレーション
* 歴史的事実の再現・検証

ハッカソンではまず、

1. LLMエージェントが自律的に社会を形成すること
2. その過程を **2D マップ**で直感的に観測できること

を完成させる。

「文明の相図」は発展機能として位置付ける。

---

## 今回重視するポイント

1. **AIエージェントが主役**であること（LLMが意思決定を担う）
2. **シミュレーションが中心**であり、UIは観測のためのインターフェースであること
3. **文明を構造化して蓄積**し、比較・再実行・分析できること
4. **社会の法則を探索する**というテーマを一貫して持つこと
