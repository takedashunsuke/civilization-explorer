# 2026-08-16

## やったこと

観測 UI を「平面世界地図で集団の形成・衝突を読む」形に寄せた（[ADR 0006](../decisions/0006-flat-map-primary.md)）。`c2adb2d` までの地図・色・折りたたみに加え、ヘッダー件数と初期条件モーダルを入れた。

### 地図

- 既定ビューを **平面**（`WorldMap2D.vue`）、地球儀はタブ。テクスチャは Natural Earth 50m 陸地（`landRings.json` / `physical.json`）と標高（`public/earth/elevation.bin`）
- 気候帯塗りをやめ、平野を明るく高地を暗くした
- 集団は HEX 色＋メンバー凸包。人数で集団／都市（8+）／国家（20+）。当該ターンの争いは破線
- 既定の全体表示は南極側下 1 割を外して拡大。＋−の横に全体へ戻すボタン

### 画面

- 初期条件は **中央モーダル**（作成後に閉じる。ヘッダーから再表示）
- 出来事は右下の **チャット型パネル**
- 地図は常時全幅。タブタイトルは Civilization Explorer
- ヘッダーを 2 段にし、人口・富・幸福をやめて件数指標にした（集団・都市・国家・未所属・争い・共同・特異）

## 決めたこと

- 衛星写真は使わない（ADR 0005 のテクスチャ方針は維持。主画面の既定は ADR 0006 で平面）
- ヘッダーは抽象スコアではなく、地図上で数える事実を出す
- 都市・国家はルール層の型ではなく観測ラベル
- 川は概ね scalerank ≤ 4 ＋日本の石狩・利根・最上、イギリスのテムズ。大湖は 110m 級のみ

## 次やること

- 侵略・吸収をルールとして明示するなら、可視化の衝突線と揃える
- 都市／国家の人数しきい値はデモを見て調整してよい
