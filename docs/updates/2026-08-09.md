## 決めたこと

- スキーマ・マイグレーション・クエリは Drizzle（`frontend/server/db/`）
- FastAPI はシミュレーション／LLM のみ（Postgres 直結しない）
- SQLAlchemy は採用しない
- Auth.js / Supabase Auth は採用しない。Web 公開時は Better Auth（MVP は未実装）
- `simulations.owner_id` は公開導入時に列追加（MVP スキーマには持たない）
- 当面の意思決定はヒューリスティック（LLM は Phase 2）
- 永続化はメモリのみ（Drizzle / Supabase は Phase 4）
