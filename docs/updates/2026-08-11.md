## 決めたこと

- UI 文言の正本は `frontend/i18n/locales/{ja,en}.json`
- 既定ロケールは `ja`（cookie: `civ_locale`）
- 人口上限は当面 100（O(n²) の関係構築のため）
- 開始年は天文年（AD 1=1, BC 1=0）で `world.start_year` に保存。現在年 = start_year + turn
- 日本元号データは `frontend/app/utils/japanNengo.ts`（`scripts/parse_eras.py` で再生成可）

- 出来事詳細を `detail_key` で構造化し、JA/EN 翻訳
- 幸福・富が高いと出生し、人口が上限 100 まで増える
- 集落は距離 10・2人以上のみ。色分けと集落円をマップに表示
- ヘッダーに人口・富・幸福・特異の全体値と増減を表示
- 集落リーダーを濃色＋輪、カリスマ★／天才◆を表示
- 加齢・死亡・出生で主体が入れ替わる。リーダーとカリスマ／天才も固定せず交代する
- 出来事は集落単位に集約（個人の待機ログは出さない）
