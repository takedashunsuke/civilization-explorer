# デモ台本

> ステータス: 下書き（時間は仮）。根拠: [review.md](./review.md) / [overview.md](./overview.md)

総時間の目安: **5〜7 分**（発表枠に合わせて調整）

| 分 | 内容 | 話すこと |
|----|------|----------|
| 0:00–0:40 | 立ち位置 | 支援 AI ではなく、AI Agent が社会を創発する実験場であること |
| 0:40–1:20 | 問い | 例: 格差 / 権力 / 少数派に優しい文明は生まれるか（1 つに絞る） |
| 1:20–2:00 | 画面 | 左: 条件（PrimeVue）/ 右: 2D マップ。人間は法則と初期条件だけ |
| 2:00–4:00 | ライブデモ | 作成 → 開始 → tick。移動・所属色・Event。創発を指差し |
| 4:00–5:00 | 仕組み | LLM は意思決定のみ、結果はルール層。蓄積・再実行で「何度も試す」土台 |
| 5:00–5:40 | 次の一歩 | 大量生成・共通点抽出はビジョン。まずはループを回す |
| 予備 | 録画切替 | ライブ失敗時は録画へ |

## 操作手順（ライブ）

1. Frontend / Backend / Supabase / Ollama（または外部 API）が起動していることを確認
2. 見せる問いにつながるパラメータを **1〜2 個だけ** 変える（例: 税率・初期格差）
3. Start → 数 tick
4. マップ上の変化とタイムラインを指差しで説明（「誰が集まり、何が起きたか」）
5. （余裕があれば）同条件再実行 or 過去 Simulation の読込

詳細な起動順は [checklist.md](./checklist.md) へ。

## 言ってはいけない一言（評価軸ずれ防止）

* 「正解の制度を AI が提案します」
* 「業務を効率化します」
