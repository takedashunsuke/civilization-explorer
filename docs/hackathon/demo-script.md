# デモ台本

> ステータス: 実装同期版（2026-08-28）。根拠: [review.md](./review.md) / [overview.md](./overview.md)

総時間の目安: **5〜7 分**（発表枠に合わせて調整）

| 分 | 内容 | 話すこと |
|----|------|----------|
| 0:00–0:40 | 立ち位置 | 支援 AI ではなく、AI Agent が社会を創発する実験場であること |
| 0:40–1:20 | 問い | 例: **制度は、次に生き残りやすい人物タイプをどう選別するか**（1 つに絞る） |
| 1:20–2:00 | 画面 | 中央: 初期条件モーダル / 全面: 平面地図 / 左: 状況パネル / ヘッダー: Tick |
| 2:00–4:00 | ライブデモ | 作成 → Tick。点在する個人・集団領域・状況パネルの地域観測を指差し |
| 4:00–5:00 | 仕組み | LLM は地域観測と集団方針のみ。数値解決はルール層。失敗時はヒューリスティック |
| 5:00–5:40 | 次の一歩 | 蓄積・再実行の土台。大量生成・相図はビジョン |
| 予備 | 録画切替 | ライブ失敗時は録画へ |

## 操作手順（ライブ）

1. Backend / Frontend が起動していることを確認（LLM 使用時は Ollama も起動し `LLM_PROVIDER=ollama`）
2. ヘッダーの LLM 状態が `ollama`（または `openai`）になっているか確認。遅い場合は `stub` でも可
3. 初期条件モーダル（3ステップ）で見せる問いにつながるパラメータを **1〜2 個だけ** 変える（例: 税率・制度）
4. 作成 → 準備オーバーレイが消えるまで待つ → Tick × 数回（または自動再生）
5. **状況パネル**（地図左の「状況」）で地域の緊張・繁栄・軌道を読む
6. 地図上の変化と **出来事** を指差しで説明（「誰が集まり、何が起きたか」）
7. （余裕があれば）同 seed で税率だけ変えた2本目を短く対照

詳細な起動順は [checklist.md](./checklist.md) / [../guides/setup.md](../guides/setup.md) へ。

## 画面の見せ方

| 場所 | 指差す内容 |
|------|------------|
| 地図 | 複数キャンプから点在する個人、集団の色面、争いの破線 |
| 状況パネル | 地域ごとの緊張・繁栄・不満・結束、台頭人物・軌道、観測ソース（LLM / ヒューリスティック） |
| ヘッダー | 西暦、集団／都市／国家件数、当ターンの争い・共同 |
| 出来事 | 集団単位の行動、体制遷移、災害。LLM 由来にはバッジ |
