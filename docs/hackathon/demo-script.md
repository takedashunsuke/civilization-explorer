## ライブ操作（推奨順）

1. Backend / Frontend 起動（任意: Ollama + `LLM_PROVIDER=ollama`）
2. 初期条件 → シナリオ **「対照実験（同一5000人×4世界）」**
3. **作成**（WORLD A 平和から開始・自動再生）
4. **+100年** または +50年 ×2。状況パネルを開く
5. ヘッダー **A 平和 / B 飢饉 / C 戦争 / D 交易** で世界切替（各 +100年）
6. 状況パネル **「100年後の差」** 表で世界比較を見せる
7. **「同じ人間なのに、役割が変わった」** — 台頭タイプ列の差を指す
8. 地図の点を **クリック** → 人物ズーム → 「なぜ？」
9. （余裕）出来事で体制転換・争い → 人物が環境を変える

## 指差しポイント

| 場所 | 言うこと |
|------|----------|
| シナリオ説明 | seed・人格・位置は固定。変えるのは環境だけ |
| 地図 | 同じ 5000 人が動いている（ID は実験間で同一） |
| 比較表 | 人口・交易・紛争・台頭タイプの**意外な差** |
| 人物パネル | 性格は同じ。環境が違うから役割が違う |
| LLM バッジ | 解釈は LLM、数値はルール |

## 言ってはいけない

- 「条件を変えたら結果が変わりました」（当たり前で終わる）
- 「偉人が歴史を作った」（一方通行）
- 「人間を支援する AI」

## 障害時

| 症状 | 対処 |
|------|------|
