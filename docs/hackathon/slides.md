## 推奨構成（7〜9 枚）

1. タイトル / チーム（Civilization Explorer）
2. ハッカソンの評価軸（Agent・相互作用・創発・人工社会）
3. 第1回との差分（支援 AI → 実験場）※短く、責めず学びとして
4. コンセプト（What if / 人間は条件、AI は文明）
5. 探究したい問い（格差・権力・幸福・少数派から **1〜2**）
6. アーキテクチャ（1 枚図）
7. デモ（ここが本番。スライドは最小）
8. MVP と次（蓄積・再実行 → 将来の大量生成）
9. クレジット / リポジトリ

## 1 枚図に載せる要素

* 人間: 初期条件・制度（世界の法則）
* LLM Agent: 意思決定（主役）
* ルール層: 結果の確定
* 2D マップ + Event: 観測
* Postgres（Supabase）: 蓄積・再実行

## トーン

* 「証明」ではなく「探索」
* 「便利ツール」ではなく「人工社会の実験」
* 自分らしさは **人間社会への問い** として最後に一言でよい
