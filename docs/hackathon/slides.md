# もし、同じ人間が違う世界に生きていたら？

Civilization Explorer

A simulation of civilization, people, and history.

同一の 5,000 人を、環境だけ違う 4 つの世界に置き、100 年後の社会と人物の差を観測する。

# 歴史は、人物の物語だと思いがち

カエサル、ナポレオン、ガンジー……私たちは人物に注目する。

しかし、その人物が別の時代・別の土地・別の社会に生まれていたら、同じように台頭しただろうか。

---

# 人間だけでは、歴史は決まらない

環境（資源・戦争・交易・人口・災害・制度）

↓ 社会の状態 ↓ 人々の行動 ↓ 集団・制度・人物 ↓ 社会が変化 ↺

人間が社会を作ると同時に、社会が人間の行動を形作る。

# 同じ 5,000 人 × 4 つの異なる世界

固定：Agent ID・人格・初期位置・人口・seed（42）

変える：資源・災害・制度・税率・交易・福祉（環境だけ）

Peace / Famine / War / Trade — 各 100 年

対照実験。なんとなく AI を動かしたデモではない。

# 五大陸を、実際に動かす

平面世界地図で個人・集団・争いを見る

状況パネルで緊張・繁栄・軌道・台頭タイプを読む

# 100 年後、世界はどう変わった？

4 世界を並べる：人口・交易・紛争・台頭タイプ

条件を変えたら結果が変わった、だけではない

同じ人間なのに、社会の形が分かれた

# 同じ人間が、違う人物になった

人物 X（同一 ID・同一性格）

WORLD A → 商人として成功

WORLD B → 軍事指導者として台頭

WORLD C → 改革者として台頭

能力の差ではない。環境との相互作用が役割を変えた。

なぜ？

# なぜ彼は、この世界では軍事指導者になったのか？

性格：野心・協調・攻撃

環境：食料・紛争・人口圧

結果：集団規模・台頭タイプ

Simulation = 世界を作る / LLM = 世界を読み解く

---

# 人物が、今度は世界を変える

人物の台頭で終わらない

争い・体制転換・交易が環境を変える

環境 → 人間 → 環境

歴史は人物だけ、環境だけではない。フィードバックで生まれる。
