## 対照実験（demo-v3 標準シナリオ）

シナリオ: **対照実験（同一 5000 人 × 4 世界）** — `experiment_seed: 42`、列あたり 1000 人。

| 世界 | variant | 環境の意図 |
|------|---------|------------|
| A | Peace | 平和・資源豊富 |
| B | Famine | 飢饉・災害多 |
| C | War | 戦争・緊張 |
| D | Trade | 交易・開放 |

各世界で **+100年**（または +50年 ×2）後の値を記入。

### 100 年後の比較（定量）

| 指標 | A 平和 | B 飢饉 | C 戦争 | D 交易 |
|------|--------|--------|--------|--------|
| 生存人口 | | | | |
| 交易（当該ターン） | | | | |
| 争い（当該ターン） | | | | |
| 台頭タイプ（代表） | | | | |
| 観測ソース（llm / heuristic） | | | | |

### 意外な差（定性・山場用）

同一 Agent ID で世界ごとに役割が違った例を 1〜3 件:

| Agent ID | A | B | C | D | 発表で指差す画面 |
|----------|---|---|---|---|------------------|
| （例） | 商人 | 軍事指導者 | 改革者 | | 比較表・人物パネル |
| | | | | | |
| | | | | | |

ズーム用メモ（1 人選んだ場合）:

- ID / 性格（野心・協調・攻撃）
- その世界の環境（食料・紛争・人口圧）
- LLM 解釈の要約（接続時）

## いま言えること（コード現状）

- 対照実験: `controlled_experiment: true`, `experiment_variant`, `experiment_seed: 42`
- Create → Tick で移動・協力・争い、状況パネルに緊張・繁栄・軌道・台頭人物
- `stub` でも完走。LLM は `/health` の `llm.wired: true` で確認

---

## 失敗・制限

| 内容 | 影響 |
|------|------|
| LLM 遅延・失敗 | ヒューリスティックへ。`stub` または録画 |
| 永続化なし | 再起動で sim 消える |
| 5000 人 | 作成・tick が重い。障害時は [checklist.md](./checklist.md) |
| 全員 LLM ではない | 地域観測 + サンプル実行モデル |
