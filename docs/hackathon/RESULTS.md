## 共通操作

1. Backend / Frontend を起動する
2. 初期条件モーダルでパラメータを入れる
3. 作成 → Tick（または自動再生）
4. 平面地図の領域・争い破線と、出来事パネルを見る

観測の読み方: 色面＝集団の領域。人数で集団／都市／国家ラベル。赤破線＝当該ターンの争い。

## いま言えること（コード現状）

- Create → Tick でエージェントが移動・協力・争い、集落が形成される
- 地形（大陸／島）と気候（温帯／寒冷／湿地／乾燥）は地形グリッドと移動コスト・資源回復に効く
- 平面地図の舞台枠に気候の色が乗る
- **LLM が行動を選んだ結果ではない。** 数値の差はヒューリスティックの傾向であり、創発の「感触」の確認用

LLM 接続後は、同じ表に「stub」と「LLM」を1行ずつ足す。

## 失敗・制限

| 内容 | 影響 |
|------|------|
| LLM 未接続 | 評価軸「エージェントが意思決定する」は未達。発表では明示する |
| 永続化なし | 再起動でサーバ上の sim は消える。再実行は seed の再入力 |
| Agent 数上限 | 列あたり 100〜1000。人数が多いと作成が重いのでデモは 100 前後から |
| 地球儀 | コンポーネントは残すが UI からは出さない |
