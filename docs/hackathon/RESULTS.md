## 共通操作

1. Backend / Frontend を起動する（LLM 使用時は Ollama も起動し `LLM_PROVIDER=ollama`）
2. 初期条件モーダル（3ステップ）でパラメータを入れる
3. 作成 → Tick（または自動再生）
4. 平面地図の領域・争い破線、**状況パネル**、**出来事**を見る

観測の読み方: 色面＝集団の領域。人数で集団／都市／国家ラベル。赤破線＝当該ターンの争い。状況パネル＝地域ごとの緊張・繁栄・不満・結束・軌道。

## いま言えること（コード現状）

- Create → Tick でエージェントが移動・協力・争い、集落が形成される
- 列内の初期配置は複数キャンプに分散し、地図上で個人が点在して見える
- ターン末に地域ごと観測（LLM 接続時）し、状況パネルに緊張・繁栄・不満・結束・軌道が出る
- 次ターンは集団方針に沿い、列あたり最大 12 人のサンプル実行者が行動する
- `LLM_PROVIDER=stub` でも完走する。`ollama` / `openai` は `/health` の `llm.wired: true` で確認

LLM 接続後は、同じ表に `stub` と `ollama`（または `openai`）を1行ずつ足す。

## 失敗・制限

| 内容 | 影響 |
|------|------|
| LLM 遅延・失敗 | ヒューリスティックにフォールバック。デモ中は `stub` または録画に切替可 |
| 永続化なし | 再起動でサーバ上の sim は消える。再実行は `replay` API またはパラメータ再入力 |
| Agent 数 | 列あたり 1000〜10000。人数が多いと作成・tick が重いのでデモは 1000 前後から |
| 全員 LLM 意思決定ではない | 地域観測 + サンプル実行モデル。大規模人口でもデモ可能にするため |
| 地球儀 | コンポーネントは残るが UI からは出さない |
