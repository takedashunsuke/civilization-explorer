## 設計

### 中心の問い

# もし、同じ人間が違う世界に生きていたら？

**A simulation of civilization, people, and history.**

制度が人物を選別する、文明が偉人を生む——という**結論を先に見せる**のではなく、

> **世界を変えて実験したら、こんな社会が創発した**

という発見の順で見せる。

### 仮説

文明の外的環境は人々の行動を変え、その中から新しい社会の担い手が生まれる。制度・争い・交易は最初から決めず、**創発**させる。

```text
設定: 共有資源・災害（食の背景・気候・地理は固定）
創発: 戦争・交易・人口圧・制度
        ↓
   社会の状態 → 人々の行動 → 集団・制度・人物 → 社会が変化 ↺
```

### Controlled experiment

概念の全体像（四層モデル・現実の資源との対応）は [world-model.md](./world-model.md)。

単に `seed=42` では不十分。**同一ロスター**を 4 世界に投入する。

| 固定 | 変更（外的環境のみ） |
|------|----------------------|
| Agent ID | 共有資源 `resource_pool` |
| personality・traits | 災害 `disaster_frequency` |
| 初期位置 | （他パラメータは全列同一） |
| 列あたり人口 1000（計 5000） | |
| seed（42） | |
| 各地域の食・気候・地理（サブ地域背景） | |
| 初期制度（全列 anarchy）・税 5%・交易 0.5・福祉 0 | |

**4 環境パターン（API / UI 共通）**

| UI ラベル | variant id | 意図 |
|-----------|------------|------|
| 豊か | `lush` | 共有資源多・災害少 |
| 乏しい | `lean` | 共有資源少・災害やや多 |
| 災害多 | `volatile` | 災害頻度高 |
| 標準 | `balanced` | 中間（比較の基準線） |

```text
     同一 Agent Population（seed 42）
            ↓
   ┌────────┼────────┬────────┐
  豊か    乏しい   災害多    標準
 lush     lean   volatile  balanced
   ↓        ↓        ↓        ↓
 100年     100年     100年     100年
（100年ごとにマイルストーンで停止。上限は西暦 2500 年）
```

API: `POST /simulations` に `controlled_experiment: true`, `experiment_variant`, `experiment_seed: 42`。  
設計詳細: `GET /experiments/design`。

### 山場（理想と現状）

**言いたいこと:** 同じ名簿なのに、創発した社会・担い手の出方が世界で違う。

**現状:** 世界レベルの差（人口・災害・体制転換・台頭タイプ）は出るが、**同一人物の役割差は未実証・UI 未接続**。詳細は [gap.md](./gap.md)。

審査員の「条件を変えたら結果が変わりました」への先回り:

- controlled experiment の 1 枚（固定 vs 変更は **共有資源と災害のみ**。食の背景は固定）
- 4 環境のヘッダー切替で数値・状況パネルを比べる
- 実測値は [RESULTS.md](./RESULTS.md) を根拠に話す（未記入なら先に実測）

### LLM の役割

| 層 | 役割 |
|----|------|
| Simulation（ルール層） | 世界を作る・数値を解決する |
| LLM（または stub） | 結果を読み解く（地域ごとの緊張・台頭タイプ等） |

LLM に歴史を作らせない。`LLM_PROVIDER=stub` でもデモ完走可。

### 実装優先度

**P0:** 4 環境 + 同一ロスター / 用語統一 / RESULTS 実測  
**P1:** +100年比較表 UI / 同一 ID の手動比較  
**P2:** バランス調整・人物ズーム強化  
**後回し:** 支持者数トラッキング / 4 本バッチ・永続化一覧 UI

### v2 との違い（前一案は人物先行・未保存）

| | v2（前一案） | v3（採用） |
|--|-----|------------|
| 主役 | 人物の台頭・★ | 世界の差 → その結果としての人物 |
| 山場 | 4 条件で誰が生まれたか表 | **同一名簿・違う創発**（人物役割差は問いとして実測） |
| 外的条件 | 曖昧 | **共有資源と災害のみ**を明示（食はサブ地域背景として固定） |
| 人物 | 序盤から前面 | 状況パネル・実測後にズーム |

### 補足：TimeMap との位置づけ

[TimeMap / OldMapsOnline](https://www.oldmapsonline.org/ja/history/regions) は世界観が近い（地図 × 時間、人物・境界）。差別化:

| | TimeMap | civ-explorer |
|--|---------|--------------|
| 問い | 実際の歴史はどう変わったか | **同じ人間が別の世界にいたらどうなるか** |
| データ | 史料・古地図 | **シミュレーション** |
| 操作 | 観察 | **条件を変えて実験** |

> TimeMap は地図で歴史を**読む**。civ-explorer は地図で歴史を**実験する**。

最初の 30 秒で「TimeMap とは違う。実験だ」と切る。

## 発表当日

### ライブ操作（事前に起動）

1. Backend / Frontend 起動（任意: Ollama + `LLM_PROVIDER=ollama`）
2. シナリオ **「対照実験（同一5000人×4環境）」** → 環境 **豊か** を選んで **作成**（自動再生）
3. **100 年**（マイルストーン or 自動再生）→ 状況パネル
4. ヘッダー **豊か / 乏しい / 災害多 / 標準** で切替（各 100 年まで進める）
5. 人口・災害・体制転換・台頭タイプの差を口頭で比較（比較表 UI は未接続の場合は RESULTS または状況パネルで）
6. 地図の点 **クリック** → その世界での地域観測を読む
7. （余裕）体制転換イベント → 社会が環境を変えるフィードバック

起動: [checklist.md](./checklist.md) / [../guides/setup.md](../guides/setup.md)

### 指差しポイント

| 場所 | 言うこと |
|------|----------|
| シナリオ説明 | seed・人格・位置は固定。**変えるのは共有資源と災害だけ**（食の背景は列ごとに固定） |
| 地図 | 同じ 5,000 人（ID は実験間で同一） |
| 環境切替 | 豊か / 乏しい / 災害多 / 標準 — 創発の差 |
| 状況パネル | 緊張・繁栄・軌道・台頭タイプ（観測ソース表示） |
| LLM バッジ | 解釈は LLM または stub、数値はルール |

### 言ってはいけない

- 「条件を変えたら結果が変わりました」（当たり前で終わる）
- 「偉人が歴史を作った」（一方通行）
- 「人間を支援する AI」
- Peace/Famine/War/Trade（実装と違う旧名称）
- 同一人物の役割差を**実測前に断定**
