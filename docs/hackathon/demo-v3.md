## 設計

### 中心の問い

# もし、同じ人間が違う世界に生きていたら？

**A simulation of civilization, people, and history.**

制度が人物を選別する、文明が偉人を生む——という**結論を先に見せる**のではなく、

> **世界を変えて実験したら、こんな社会と人物が生まれた**

という発見の順で見せる。

### 仮説

文明の環境は人々の行動を変え、その中から新しい社会の担い手が生まれる。

```text
環境（資源・戦争・交易・人口・災害・制度）
        ↓
   社会の状態 → 人々の行動 → 集団・制度・人物 → 社会が変化 ↺
```

### Controlled experiment

単に `seed=42` では不十分。**同一ロスター**を 4 世界に投入する。

| 固定 | 変更（環境のみ） |
|------|------------------|
| Agent ID | 資源 `resource_pool` |
| personality・traits | 災害 `disaster_frequency` |
| 初期位置 | 制度・税率 |
| 列あたり人口 1000（計 5000） | 交易・福祉 |

```text
     同一 Agent Population（seed 42）
            ↓
   ┌────────┼────────┬────────┐
 Peace   Famine    War    Trade
   ↓        ↓        ↓        ↓
 100年     100年     100年     100年
```

API: `POST /simulations` に `controlled_experiment: true`, `experiment_variant`, `experiment_seed: 42`。  
設計詳細: `GET /experiments/design`。

### 山場

4 世界の表は**補助**。本当の山場は:

> 同じ人物 X が、WORLD A では商人、B では軍事指導者、C では改革者

**人物の能力ではなく、環境との相互作用が役割を変えた**——ここを口と画面で突く。

審査員の「条件を変えたら結果が変わりました」への先回り:

- controlled experiment の 1 枚（固定 vs 変更）
- 同一 agent ID を地図・状況パネルで指差す
- 「なぜ？」をデータ根拠で掘る（LLM = 解釈のみ）

### LLM の役割

| 層 | 役割 |
|----|------|
| Simulation（ルール層） | 世界を作る・数値を解決する |
| LLM | 結果を読み解く（災害・紛争・移動・人格を根拠に説明） |

LLM に歴史を作らせない。

### 実装優先度

**P0:** 4 環境 + 同一ロスター / +100年比較 / 人物クリックズーム  
**P1:** 人物→環境変化ストーリー / クロスワールド役割比較  
**後回し:** 支持者数トラッキング / 4 本バッチ・永続化一覧 UI

### v2 との違い（前一案は人物先行・未保存）

| | v2（前一案） | v3（採用） |
|--|-----|------------|
| 主役 | 人物の台頭・★ | 世界の差 → その結果としての人物 |
| 山場 | 4 条件で誰が生まれたか表 | **同一人間の意外な役割差** |
| 問い | 文明はどんな人物を生むか（先に立てる） | 同じ人間・違う世界（実験から入る） |
| 人物 | 序盤から前面 | 後半のズームで初めて前面 |

### 補足：TimeMap との位置づけ

[TimeMap / OldMapsOnline](https://www.oldmapsonline.org/ja/history/regions) は世界観が近い（地図 × 時間、人物・境界）。差別化:

| | TimeMap | civ-explorer |
|--|---------|--------------|
| 問い | 実際の歴史はどう変わったか | **同じ人間が別の世界にいたらどうなるか** |
| データ | 史料・古地図 | **シミュレーション** |
| 操作 | 観察 | **条件を変えて実験** |

> TimeMap は地図で歴史を**読む**。civ-explorer は地図で歴史を**実験する**。

最初の 30 秒で「TimeMap とは違う。実験だ」と切る。

## 発表当日

### ライブ操作（事前に起動）

1. Backend / Frontend 起動（任意: Ollama + `LLM_PROVIDER=ollama`）
2. シナリオ **「対照実験（同一5000人×4世界）」** → **作成**（WORLD A・自動再生）
3. **+100年** → 状況パネル
4. ヘッダー **A 平和 / B 飢饉 / C 戦争 / D 交易** で切替（各 +100年）
5. **「100年後の差」** 表 → 台頭タイプ列の差を指す
6. 地図の点 **クリック** → 「なぜ？」
7. （余裕）体制転換・争い → 人物が環境を変える

起動: [checklist.md](./checklist.md) / [../guides/setup.md](../guides/setup.md)

### 指差しポイント

| 場所 | 言うこと |
|------|----------|
| シナリオ説明 | seed・人格・位置は固定。変えるのは環境だけ |
| 地図 | 同じ 5000 人（ID は実験間で同一） |
| 比較表 | 人口・交易・紛争・台頭タイプの**意外な差** |
| 人物パネル | 性格は同じ。環境が違うから役割が違う |
| LLM バッジ | 解釈は LLM、数値はルール |

### 言ってはいけない

- 「条件を変えたら結果が変わりました」（当たり前で終わる）
- 「偉人が歴史を作った」（一方通行）
- 「人間を支援する AI」
