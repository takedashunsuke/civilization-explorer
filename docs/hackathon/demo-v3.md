## 中心の問い

# もし、同じ人間が違う世界に生きていたら？

**A simulation of civilization, people, and history.**

制度が人物を選別する、文明が偉人を生む——という**結論を先に見せる**のではなく、

> **世界を変えて実験したら、こんな社会と人物が生まれた**

という発見の順で見せる。

## 仮説（一行）

文明の環境は人々の行動を変え、その中から新しい社会の担い手が生まれる。

```text
環境（資源・戦争・交易・人口・災害・制度）
        ↓
   社会の状態 → 人々の行動 → 集団・制度・人物 → 社会が変化 ↺
```

## Controlled experiment（実装で固定）

単に `seed=42` では不十分。**同一ロスター**を 4 世界に投入する。

| 固定 | 変更（環境のみ） |
|------|------------------|
| Agent ID | 資源 `resource_pool` |
| personality・traits | 災害 `disaster_frequency` |
| 初期位置 | 制度・税率 |
| 列あたり人口 1000（計 5000） | 交易・福祉 |

```text
     同一 Agent Population（seed 42）
            ↓
   ┌────────┼────────┬────────┐
 Peace   Famine    War    Trade
   ↓        ↓        ↓        ↓
 100年     100年     100年     100年
```

API: `POST /simulations` に `controlled_experiment: true`, `experiment_variant`, `experiment_seed: 42`。  
設計詳細: `GET /experiments/design`。

## デモの骨格（問い → 実験 → 結果 → 問いの反転）

1. **問い** — 同じ人間でも、違う世界なら違う歴史か
2. **実験** — 五大陸・同一 5000 人・4 環境（UI: 対照実験シナリオ）
3. **100年後** — 世界の差（人口・交易・紛争）。「当たり前の比較」で止めない
4. **意外な差** — 同一人物 ID が世界ごとに違う役割（商人 / 軍事指導者 / 改革者）
5. **ズーム** — 1 人クリック。「なぜ？」= 環境 × 個性 × 出来事
6. **逆方向** — 人物 → 制度・争い → 環境変化（フィードバック）
7. **問いに戻る** — 人間が歴史を作る / 歴史が人間を作る → **両方**
8. **現代** — AI 時代はどんな人間を生むか

## 山場は「比較表」ではなく「意外な差」

4 世界の表は**補助**。本当の山場は:

> 同じ人物 X が、WORLD A では商人、B では軍事指導者、C では改革者

**人物の能力ではなく、環境との相互作用が役割を変えた**——ここを口と画面で突く。

審査員の「条件を変えたら結果が変わりました」への先回り:

- controlled experiment の 1 枚（固定 vs 変更）
- 同一 agent ID を地図・状況パネルで指差す
- 「なぜ？」をデータ根拠で掘る（LLM = 解釈のみ）

## LLM の役割

| 層 | 役割 |
|----|------|
| Simulation（ルール層） | 世界を作る・数値を解決する |
| LLM | 結果を読み解く（災害・紛争・移動・人格を根拠に説明） |

LLM に歴史を作らせない。

## 補足：TimeMap との位置づけ

[TimeMap / OldMapsOnline](https://www.oldmapsonline.org/ja/history/regions)（[Product Hunt](https://www.producthunt.com/products/timemap) で「The Google Maps of History」）は、今回のシミュレーションと**世界観がかなり近い**。

共通する骨格:

- **地図 × 時間軸**で文明を眺める
- 国境・支配者・戦争・その時代の人物が見える
- 「その時代・その土地に生まれた人物」という視点

demo-v3 の問い——同じ人間が違う世界にいたらどうなるか——も、TimeMap が自然に連想させる歴史観と親和性が高い。

### 決定的な違い（差別化）

| | TimeMap | civ-explorer |
|--|---------|--------------|
| 問い | 実際の歴史はどう変わったか | **同じ人間が別の世界にいたらどうなるか** |
| データ | 史料・古地図・アーカイブ | **シミュレーション（人工世界）** |
| 操作 | 観察・探索 | **条件を変えて実験** |
| 人物 | 記録された偉人・支配者 | **環境から湧き上がる担い手** |
| LLM | なし（または補助） | **ルールが歴史を作り、LLM は解釈のみ** |

- TimeMap は **「過去を辿る地図」** — 史料が示す一つの世界を見る
- civ-explorer は **「反実仮想を試す地図」** — 史料には存在しない分岐を見る

### デモ・ピッチでの一言

> TimeMap は地図で歴史を**読む**。  
> civ-explorer は地図で歴史を**実験する**。

または:

> TimeMap は「歴史が実際にどう進んだか」を見せる。  
> 私たちは「**同じ人間が、違う環境にいたら何が起きるか**」を試す。

UI 面でも、TimeMap の「スライダーで時代を動かす」「地図上で人物・境界を見る」は `WorldMap2D` + ターン進行 + 状況パネルと親和性が高い。審査員は見た目の期待値をすでに持っている——**似ているのに新しい**という印象はデモの強み。

ただし v3 は「人物を前面に出さない」「環境の差から入る」設計なので、**最初の 30 秒で「TimeMap とは違う。実験だ」** と切ると、近さと差別化が両立しやすい。
