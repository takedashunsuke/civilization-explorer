# 想定質問（FAQ）

> ステータス: 実装同期版（2026-08-28）

| 質問 | 回答の要点 |
|------|------------|
| 予測ツールでは？ | 予測でも証明でもない。条件を変えて創発を観察する仮説探索 |
| 人間の意思決定支援では？ | 第1回はその方向だったが評価軸とずれた。今回は AI 社会の創発が主役 |
| AI 文明に興味があるのか？ | 文明そのものより、それを使って人間社会の問いを探りたい |
| 格差は悪だと証明する？ | しない。ある条件で何が生まれるかを見る実験 |
| なぜ 2D？ | 観測しやすさと実装速度。地球・本格 3D は MVP 外 |
| LLM に全部任せる？ | 地域観測と集団方針のみ。数値解決はルール層 |
| 再現性は？ | seed と初期パラメータを保存し同条件再実行（`GET /replay`）。LLM 時は傾向観察 |
| 何千回回すのか？ | 長期ビジョン。ハッカソンではループ成立と観測を優先 |
| なぜ Supabase？ | ローカルで Postgres を Docker 起動しやすい。ORM は Drizzle（Nuxt 側）。MVP では未接続 |
| なぜログインがない？ | MVP はローカル単一利用者。将来 Web 公開時は Better Auth + Drizzle |
| スケールは？ | 列あたり 1000〜10000 人。LLM は地域観測 + 列あたり最大 12 人のサンプル実行 |
| チャットボットとの違いは？ | Agent 同士が社会を形成する。人間との対話 UI が主目的ではない |
