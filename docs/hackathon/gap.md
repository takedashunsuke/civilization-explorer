## 方針（発表で言いたいこと）

| 項目 | 内容 |
|------|------|
| 中心の問い | 同じ人間が、違う外的環境にいたらどうなるか |
| 手法 | **対照実験** — 同一 5,000 人ロスター × 環境だけ違う 4 世界 |
| デモの時間軸 | **100 年**を区切りに観測（100 年ごとにマイルストーンで一時停止） |
| シミュレーションの上限 | 西暦 **2500 年**まで進行可能（1 ターン＝10 年） |
| 山場（理想） | 世界の差 → 同一人物の役割差 → 1 人ズームで「なぜ？」 |
| LLM | 歴史は作らない。地域観測と解釈のみ（`stub` 時はヒューリスティック） |

## ギャップ（方針と実装のずれ・問題）

### 1. 用語・概念（ドキュメント間の不一致）— **スライド修正で対応済み**

| 旧表現（スライド等） | 実装の正 |
|---------------------|----------|
| Peace / Famine / War / Trade | **豊か / 乏しい / 災害多 / 標準**（`lush` / `lean` / `volatile` / `balanced`） |
| 制度・税率・交易・福祉を変える | **共有資源と災害のみ**（食の背景は固定）。制度・争い等は創発 |
| 「食と資源」を同じように書く | **食**（固定の舞台）と **共有資源**（実験ノブ）を分ける |
| 「商人→軍事指導者→改革者」が起きる（断定） | **未実証**。観測したい問いとして扱う |

### 2. デモ山場が画面で完結しない

| 項目 | 問題 |
|------|------|
| 「100 年後の差」比較表 | i18n・CSS・`experimentComparisonRows` はあるが **テンプレート未接続** |
| 同一人物のクロスワールド役割比較 | **UI 未実装**（地図クリックは当該世界の地域観測のみ） |
| 人物ごとの「なぜ？」 | `whyTitle` 文言のみ。**Agent 単位の説明 API なし** |
| spotlight | 世界ごとに **別の Agent を選ぶことがある**。固定の「人物 X」にならない |

### 3. シミュレーション挙動（試走 seed=42、100 年）

| 指標 | 4 世界とも近い値になりやすい | 影響 |
|------|------------------------------|------|
| 生存人口 | 約 1,020 / 5,000（**約 80% 減**） | 「世界の差」が人口では弱い |
| 争い（conflict） | **0 件** | 戦争・軍事指導者のストーリーが出ない |
| 台頭タイプ | 全地域 **merchant** 寄り | スライドの役割差デモと矛盾 |
| 交易 | 全世界 **0.5**（初期値のまま） | 比較表の「交易」列に差が出ない |
| 体制転換 | 2〜5 回（わずかに差） | 使える差分のひとつ |
| 災害 | 8〜12 回（variant で差） | 使える差分のひとつ |

**原因の仮説（要追加実測）**

- 台頭タイプは地域ヒューリスティック：繁栄 ≥ 0.55 かつ交易 ≥ 0.45 → `merchant`（`llm.py`）。争いが無いと `warlord` 条件に届かない。
- `spotlight_role` は人物の役割ではなく、**指導者なら所属地域の `rising_archetype` を貼る**だけ（`experiment.py` `_agent_role_label`）。
- 世界切替は `createControlledWorld` で **毎回 sim を作り直す**。比較は `experimentSummaries` に依存（永続化なし）。

## 100 年停止について

**修正不要。** 意図した UX です。

| 仕様 | 説明 |
|------|------|
| ハード上限 | 西暦 **2500 年**（`MAX_CALENDAR_YEAR`）。それ以上は tick 不可 |
| ソフト停止 | **100 年ごと**にマイルストーン modal が開き、自動再生が止まる |
| デモとの関係 | 発表は「+100 年で観測」が前提。マイルストーンと一致するので **そのまま使ってよい** |
| 続行 | modal の「そのまま続ける」で 2500 年まで進められる |
