# 概要（ハッカソン用）

> ステータス: 実装同期版（2026-08-28）。[review.md](./review.md) と整合

## 一言ピッチ

AI エージェントが社会を創発する。人間は条件を変え、その法則を探索する。  
**What if...? を繰り返し試す実験場。**

## 立ち位置（評価軸への合わせ方）

| 見せる | 見せない・言わない |
|--------|-------------------|
| AI Agent が主役で相互作用する | 人間を支援するチャット / 助言 AI |
| 世界の法則だけを与え、創発を観測する | 「正解の社会」を AI が導く |
| 格差・権力・制度などの問いを実験する | 業務効率化・便利ツール |

詳細な経緯は [review.md](./review.md)。

## 課題

現実の人間社会では、制度や格差を何千通りも試しにくい。  
一方、支援型 AI だけでは「人工社会の創発」という本ハッカソンの軸に乗らない。

## 解決

人間は初期条件・環境・制度だけを変え、LLM がターン末に地域を観測し、次ターンの集団方針として社会に反映する過程を **平面地図と状況パネルで観測**する。  
結果は `replay` API と将来の Drizzle 永続化で同条件再実行の土台を作る。

## デモで必ず見せること

1. パラメータ（制度・税率・列人口など）を変えてシミュレーションを作成できる
2. Agent が自律的に行動し、社会状態が変わる（創発の感触）
3. 平面地図・状況パネル・出来事で変化を読み取れる
4. LLM 接続時は地域観測が状況パネルに出る（未接続時はヒューリスティックで完走）

## デモでまだ見せなくてよいこと

* 文明の相図（高度な比較 UI）
* Postgres 永続化・過去一覧 UI
* 地球背景・本格 3D
* 数千回バッチ実行
* 全 Agent 個別の毎ターンフル LLM

## 自分らしさ（発表で一言）

AI 文明そのものが目的ではなく、**人間社会の問い（格差・権力・幸福・少数派）を探る実験場**として使う。
