# 概要（ハッカソン用）

> ステータス: 下書き（[review.md](./review.md) と整合）

## 一言ピッチ

AI エージェントが社会を創発する。人間は条件を変え、その法則を探索する。  
**What if...? を繰り返し試す実験場。**

## 立ち位置（評価軸への合わせ方）

| 見せる | 見せない・言わない |
|--------|-------------------|
| AI Agent が主役で相互作用する | 人間を支援するチャット / 助言 AI |
| 世界の法則だけを与え、創発を観測する | 「正解の社会」を AI が導く |
| 格差・権力・幸福などの問いを実験する | 業務効率化・便利ツール |

詳細な経緯は [review.md](./review.md)。

## 課題

現実の人間社会では、制度や格差を何千通りも試しにくい。  
一方、支援型 AI だけでは「人工社会の創発」という本ハッカソンの軸に乗らない。

## 解決

人間は初期条件・環境・制度だけを変え、LLM エージェント同士の相互作用から文明が生まれる過程を **2D マップで観測**する。  
結果は構造化して蓄積し、同条件で再実行できるようにする（大量生成・相図は発展）。

## デモで必ず見せること

1. パラメータ（制度・資源など）を変えてシミュレーションを開始できる
2. Agent が自律的に行動し、社会状態が変わる（創発の感触）
3. 2D マップと Event / メトリクスで変化を読み取れる
4. （可能なら）蓄積・同条件再実行の入口を一言示す

## デモでまだ見せなくてよいこと

* 文明の相図（高度な比較 UI）
* 地球背景・本格 3D
* 数千回バッチ実行
* 大規模人口でのリアルタイム LLM

## 自分らしさ（発表で一言）

AI 文明そのものが目的ではなく、**人間社会の問い（格差・権力・幸福・少数派）を探る実験場**として使う。
