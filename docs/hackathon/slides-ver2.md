# 問い ｜ もし、同じ人間が違う世界に生きていたら？

Civilization Explorer

A simulation of civilization, people, and history.

同一の **5,000 人**を、条件だけ違う **4 つの世界**に置き、**200 年**（表示ラベル AD 1750→1950）の創発を観測する。

環境が違えば、争い・資源・生死は分岐するのか。  
同じ危機でも、社会の組み方が違えば、運命は分かれるのか。

偉人を探す装置ではない。**人と世界の相互作用を、再現可能な人工世界で測る装置**である。

---

# 常識の疑い ｜ 歴史は、人物の物語だと思いがち

カエサル、ナポレオン、ガンジー……教科書も物語も、まず人物に名前を付ける。

しかし、その人物が別の時代・別の土地・別の制度・別の危機の並びの中に生まれていたら、同じように台頭しただろうか。同じように生き残っただろうか。

「個人の才能が歴史を作る」でも、「環境がすべてを決める」でも足りない。  
才能も性格も同じ名簿を、世界だけ変えて走らせると、**どちらが語りすぎか**が見える。

---

# 構造的課題 ｜ 世界が人を作り、人が世界を作り返す

与えるのは外的ゆとり（共有資源・災害）や、社会の初期条件（制度・協力バイアスなど）。  
土地・気候・食の説明は舞台として固定する。

戦争・交易・制度転換・指導者は最初から決めない。エージェントの相互作用から創発する。

外的環境 → 社会の状態 → 人々の行動 → 集団・制度・人物 → 社会が再び変わる ↺

国家や制度が前提の安全保障ではなく、**ショックの下で社会が協力・制度・指導を再編成できるか**。  
操作的には人口保持率・ショック後の協力比・制度破綻で測る。これがこの装置における問いの深層である。

---

# 実験デザイン ｜ 同じ 5,000 人を、条件だけ違う世界へ

**固定:** Agent ID・人格・traits・初期位置・人口・seed・五大陸の舞台（気候・地形・衛生）

**軸 A — 環境差**  
変える: 共有資源と災害だけ  
豊か / 乏しい / 災害多 / 標準  
実測: **200 年 × 10 seed**（42…51）

**軸 B — 社会差**  
変える: 制度・税・福祉・協力バイアス・権威・初期富の幅  
ショック列は 4 世界で**同一 42 件**（事前生成）  
共和・協調 / 専制・秩序 / 高福祉・共同 / 無政府・分断  
実測: stub → 1b → 8B → 上書き人数の切り分け

**見る指標:** 生存・保持率・資源・災害・争い・共同・同一 ID の生死  
**未モデル化:** 本格的な時代・産業史、資源の種類切替、商人 vs 軍閥の役割転換

---

# ソリューション（技術） ｜ 五大陸を、実際に動かす

**見える化**  
平面地図で個人・集団・出来事。状況パネルで緊張・繁栄・軌道・台頭タイプ。  
人口・資源の軌跡と比較表で、ショック後の分岐を追う。世界切替はヘッダーから。

**動かし方**  
ルール層が死亡・出生・資源・災害・制度を解決する。  
LLM は地域の観測と、サンプル住民の決定を上書きする（全住民を毎ターン LLM にはしない）。  
歴史の「正解」を生成しない — 創発を観測する。

**再現**  
CLI 一括バッチ（環境 10 seed / 社会差系列）とデモ UI。生ログと横断サマリーまで残す。

# 検証結果①（全体） ｜ 200 年後、世界はどう分岐したか

**環境差 · 10 run 平均（seed 42…51）**

| | 豊か | 乏しい | 災害多 | 標準 |
|--|------|--------|--------|------|
| 生存人口 | 820 | 819 | 826 | 818 |
| 共有資源 | **990** | **440** | 556 | 717 |
| 災害 | 12 | 18 | **28** | 16 |
| 争い | 90 | 99 | 94 | 89 |

資源・災害はノブどおり。人口は約 **84% 減**でほぼ重なる。争いは単発では劇的でも、10 run では順位が安定しない。

**社会差 · 同一ショック 42 件（`run3` · seed 42）**

| | stub | 1b | 8B（人数4） | 8B（人数1） |
|--|--|--|--|--|
| 生存 | **278**/159/236/127 | 190/182/189/93 | **10/10/10/10** | 21/23/19/20 |
| 保持率 | **0.056**…0.025 | 0.038…0.019 | **0.002** | 0.004–0.005 |
| 共同 | 0 | 数十 | **318–372** | 136–179 |
| 争い | 0 | 8–47 | ほぼ 0 | civic 5…fracture **90** |

環境は資源を動かす。社会と決定は、争い・共同・生存の並びを動かす — そして効きすぎると差が消える。

# 検証結果②（個体） ｜ 同じ人間が、違う運命になった

初期名簿 **a1–a5000** だけが、世界をまたいで同一人物として比較できる。子孫の ID は別人。

200 年後、名簿のほとんどは 4 世界すべてで死亡する（環境 run-001 では **97.6%**）。  
それでも「**1 世界だけ**生き残る」人が出る（環境 10 run 平均 **約 88 人**）。  
複数世界で生き残る人はごくまれで、同一ショック系列では **0** のこともある。

**環境差の例（run-001）**  
- **a2473**（東アジア · charisma）: 3 世界では 59 歳で死亡、**災害多だけ生存**  
- **a2867**: 豊かと災害多で生存、乏しいと標準では死亡

**社会差の例（run3-001 stub）**  
- **a2670**（genius）: **共和だけで生存し、アジアの指導者**。他 3 世界では死亡

才能の差ではない。**同じ ID でも、生き残る世界が違う。**  
200 年後の指導者の多くは子孫世代 — 初期名簿の物語は、台頭より**生死と寿命の分岐**として読む。

# メカニズム解析 ｜ なぜ、差が出る条件と消える条件があるのか

**差が出る — 同じ指導者でも、寿命が倍違う**

a4008（オセアニア · charisma + genius）は **4 世界すべてで**初期に指導者になった同一 ID。

| | 豊か | 乏しい | 災害多 | 標準 |
|--|------|--------|--------|------|
| 死亡年齢 | 132 | 112 | **72** | **142** |
| 争い（累計） | 4 | 0 | 4 | 3 |

災害多は最も早死、標準は約 2 倍長生き。環境が寿命と行動を変える。

**差が消える — 決定を強めると、共同が世界差を潰す**

決定を 8B・人数 4 にすると共同 318–372、生存は 4 世界とも 10、保持率 0.002。  
人数を 1 に落とすと共同は約半分、争いは分断が最多に戻る。だが生存は ~20 で差が薄い。

大きいモデル＝回復ではない。協力の多さ＝よい歴史、でもない。  
差が出る条件と、測り方が差を潰す条件の両方を、装置は記録できる。

# 結論（本質） ｜ 人物が、今度は世界を変える

同じ人間を違う世界に置くと、資源・災害・生死・寿命が分岐する。

同じ危機でも、社会と意思決定が違えば、共同と争いの形が分岐する。  
偏りすぎれば差は消え、その事実自体が測定の一部になる。

歴史は人物だけでも、環境だけでもない。  
**人と世界のフィードバックを、再現可能な人工世界で測れる** — きれいな成功談だけでなく、再現しにくい指標や効きすぎた条件まで含めて。

何度も試して初めて見える法則がある。そして人物が、その法則の中で世界を変え返す。

AI 時代 — 知識のコモディティ化、仕事の変化、意思決定の高速化。  
私たちは時代を作っていると思っている。しかし私たち自身も、時代によって作られているのではないか。

同じ人間でも、置かれた世界が違えば運命は分岐する。  
同じ危機でも、社会の組み方と意思決定が違えば、応答は分岐する — あるいは差が消える。

では、私たちの時代は、どんな条件の下で、どんな人間を生み出しているのか。
