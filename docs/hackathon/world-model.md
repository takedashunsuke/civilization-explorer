# 世界モデル — 何が固定で、何が変わるか

> **実装を正とする**概念整理。対照実験・発表用語の根拠。  
> ギャップと TODO は [gap.md](./gap.md)。操作は [demo-v3.md](./demo-v3.md)。

## 1. 現実とシミュレーターの距離

歴史上、「重要な資源」は時代とともに変わる。

| 時代感 | 例として重要なもの |
|--------|-------------------|
| 狩猟・採集 | 食料、水、狩場、石材 |
| 農業社会 | 耕地、灌漑水、木材、畜力 |
| 工業化 | 石炭、鉄鋼、石油、港湾 |
| 現代 | 稀土類、半導体、データ、エネルギー網 |

**この MVP では、それらを個別の変数としては持たない。**  
食料・水・木材・石油……を分けず、ルール層では主に **1 本のスカラー `resource_pool`（共有資源のゆとり）** に畳み込んでいる。

| 現実で言いたいこと | いまのシミュレーターでの扱い |
|--------------------|------------------------------|
| 食料・水・漁場・農地 | UI の **「食」叙事**（説明文のみ）＋ **`resource_pool`**（数値） |
| 木材・石炭・鉄・石油 | **未実装**（`resource_pool` に含意として畳む） |
| 海水資源・貿易路 | **未実装**（`trade_openness` は開放度スカラーのみ） |
| 時代で重要資源が変わる | **未実装**（暦年は進むが資源の種類は切り替わらない） |

発表では「簡略化した実験装置」と言い切るのが正直。  
「石油と食料を別々に回した」ように聞こえないよう、下の **4 層** で話す。

## 2. 四層モデル（全体像）

```text
┌─────────────────────────────────────────────────────────┐
│ ④ 創発（ターン進行で変化）                                │
│    集団・指導者・争い・体制転換・個人の富・人口・観測ラベル  │
├─────────────────────────────────────────────────────────┤
│ ③ 人間ロスター（対照実験では 4 世界共通で固定）            │
│    Agent ID・人格・traits・初期位置・初期年齢・所属列       │
├─────────────────────────────────────────────────────────┤
│ ② 実験ノブ（対照実験で 4 世界だけ違う）                    │
│    共有資源 resource_pool・災害 disaster_frequency         │
│    ※ 5 列すべてに同じ値で上書き                           │
├─────────────────────────────────────────────────────────┤
│ ① 舞台（1 世界の中では固定。列ごとに地理は異なる）          │
│    サブ地域・気候・地形・衛生・（UI の食の説明）             │
└─────────────────────────────────────────────────────────┘
```

**対照実験で「4 世界を比べる」とき**

- **③ は完全に同じ**（同一 5,000 人）
- **② だけを変える**（豊か / 乏しい / 災害多 / 標準）
- **① は各世界で同じ列構成**（アフリカ列＝西アフリカ、欧州列＝西欧……）
- **④ はプレイのたびに違う**（同じ seed なら再現可能）

## 3. 層ごとの詳細（実装フィールド）

### ① 舞台 — 地理・自然の背景

**役割:** 「どの土地に立っているか」。列（大陸マクロ）ごとにサブ地域が 1 つ選ばれ、そのプリセットが効く。

| 概念（人間向け） | 実装 | 数値に効く？ | 対照実験 |
|------------------|------|-------------|----------|
| サブ地域（22 区分） | `subregion_id` | ✅ 地形生成・地図投影 | 列ごと固定（既定サブ地域） |
| 気候 | `climate` | ✅ 資源回復・移動・災害の偏り | 列ごと固定 |
| 地形（内地/島国等） | `landform` | ✅ タイル生成 | 列ごと固定 |
| 衛生 | `sanitation` | ✅ 疫病確率 | 列ごと固定 |
| **食**（狩猟・農耕・漁の説明） | i18n `background.food` 等 | ❌ **叙事のみ** | 列ごと固定（表示用） |
| 内地/海側/島国（説明） | i18n | ❌ 叙事のみ | 列ごと固定 |

根拠: `continents.py` の `SUBREGION_PRESETS` / `SANITATION`、`_build_region()`。  
「食」の行はウィザードの背景表に出るが、**シミュレーションの式には入らない**。

---

### ② 実験ノブ — 外的ゆとり（対照実験で唯一いじる層）

| 概念（人間向け） | 実装 | 何に効くか | 対照実験 |
|------------------|------|-----------|----------|
| **共有資源のゆとり** | `resource_pool` | 協力時の付与、ターン末の回復、観測の「繁栄」ヒューリスティック | **4 パターンで全 5 列共通上書き** |
| **災害の起きやすさ** | `disaster_frequency` | 台風・地震・水害等の頻度（種類は気候・地形で偏る） | **同上** |

根拠: `experiment.py` の `_EXTERNAL_PATCH`、`apply_variant_to_sim()`。

**`resource_pool` が「畳んでいる」もの（明示はしないが含意）**

- 食料の余裕、水・土地の利用しやすさ、未加工の原材料の豊かさ
- **含まない:** 石油のような時代限定資源、技術によって変わる資源の価値

列ごとにプリセット値は違うが、対照実験作成時に **同じ patch で全列上書き** するため、**列間差よりパターン差** を見る設計。

---

### ③ 人間ロスター — 同一個体の実験

| 概念 | 実装 | 対照実験 |
|------|------|----------|
| 個人 ID | `agent.id` | seed=42 の名簿を 4 世界にコピー |
| 人格 | `personality`（野心・協調・攻撃） | 固定 |
| 稀少特性 | `traits`（charisma / genius 等） | 固定 |
| 初期位置 | `position`, `region_id`, `subregion_id` | 固定 |
| 初期富・年齢 | `wealth`, `age` | ID・順位は固定。resilience では `inequality` で富の**幅**だけ変える（誰が相対的に豊かかは同じ） |

根拠: `generate_agent_roster()` + `clone_roster_for_world()`。

---

### ③′ 社会の初期値 — 対照実験では中立スタート

制度・税・信条（`religion`）など。**4 世界とも同じ初期値**（創発の出発点）。

| 概念 | 実装 | 対照実験の初期値 |
|------|------|------------------|
| 制度 | `institution` | 全列 `anarchy` |
| 税率 | `tax_rate` | 5% |
| 教育 | `education_level` | 0.5 |
| 信条（UI。実装は `religion`） | `religion` | `folk` |
| 交易開放 | `trade_openness` | 0.5 |
| 福祉 | `welfare_rate` | 0 |
| 列の価値観バイアス | `initial_values` | 全員 0.5 基準 |

カスタムシナリオではここを自由に設定できる。対照実験では **意図的に中立** にしている。

---

### ④ 創発 — ターン進行で変わるもの

| 概念 | 実装・イベント | 備考 |
|------|----------------|------|
| 集団・集落 | `settlements` | 距離で自動結成 |
| 指導者 | `settlement.leader_id` | 富・野心・特性で選出 |
| 争い・協力 | `ActionType.conflict` / `cooperate` | ルール層で解決 |
| 体制転換 | `regime` イベント | `apply_regime_drift()` |
| 人口 | 出生・死亡 | `wealth` / `happiness` / 年齢 |
| 個人の富 | `agent.wealth` | 協力・争い・税で変動 |
| 共有資源の残量 | `region.resource_pool` | 消費・回復で **② の初期値から動く** |
| 台頭タイプ等 | `region_readings` | **観測層**（LLM またはヒューリスティック）。歴史の原因ではない |
| 暦年 | `start_year + turn × 10` | 表示・マイルストーン用。**資源の種類は変わらない** |

## 5. 対照実験の早見表

| | 世界 A〜D で同じ？ | 列（五大陸）間で同じ？ |
|--|-------------------|------------------------|
| ③ 人間 5,000 人 | ✅ 同じ | 人は所属列に応じて配置が違う |
| ③′ 社会初期値 | ✅ 同じ | ✅ 同じ |
| ② 共有資源・災害 | ❌ **パターンで違う** | ✅ 同じ patch で上書き |
| ① サブ地域・気候・衛生 | ✅ 同じ | ❌ 列ごとに違う（舞台の違い） |
| ① 食の叙事（UI） | ✅ 同じ | ❌ 列ごとに違う |
| ④ 創発結果 | ❌ プレイで変わる | 列ごとに変わりうる |

**一言:** 「同じ人間を、**共有資源と災害だけ違う 4 つの平行世界**に置いた。土地の違い（五大陸）は列として残し、**その上に全列共通のゆとり**を載せ替える。」

## 7. 時間（暦）の扱い

| 項目 | 実装 | 意味 |
|------|------|------|
| 1 ターン | 10 年（`YEARS_PER_TURN`） | |
| 開始年 | 既定 AD 1000（変更可） | 表示・時代ラベル用 |
| 上限 | 西暦 2500 年 | それ以上は tick 不可 |
| マイルストーン | 100 年ごとに UI 停止 | デモの観測区切り |

**暦年が進んでも、資源の「種類」は切り替わらない。** 工業化して石油が重要になる、といったモデルは将来拡張。現状は **時代非依存の抽象資源**。

## 8. 発表で使える言い換え

| 避けたい言い方 | 実装に沿った言い方 |
|----------------|-------------------|
| 食と資源を変えた | **共有資源**（`resource_pool`）と**災害**を変えた |
| 石油が豊富な世界 | （未実装）**共有資源が豊かな世界** |
| 食料が違うから結果が違う | **列ごとの食の背景は固定**；差は共有資源の patch |
| 時代で資源が変わる | **いまの MVP では暦だけ進む**；資源 taxonomy は将来 |
| LLM が歴史を作った | **ルール層が数値を決め**、LLM/stub が**読み解いた** |

## 9. 将来拡張（ドキュメント上の方向性のみ）

実装はまだない。概念だけ先に分けておく。

| 拡張 | 層 | 例 |
|------|-----|-----|
| 資源の多分化 | ② または ④ | `food`, `water`, `fuel`, `ore` スカラー |
| 時代依存 | 新層（将来） | 暦年閾値で「重要資源」セットが切り替わる |
| 交易路・海洋 | ①② | 沿岸列の `trade_openness` 初期差、港イベント |
| 技術 | ④ | 教育・制度と連動して `resource_pool` 回復式が変化 |
