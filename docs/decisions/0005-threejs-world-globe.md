# 0005. 可視化は Three.js の世界地図（地球儀）

- Status: accepted
- Date: 2026-08-11
- Supersedes: [0002](./0002-2d-visualization.md)

## Context

2D Canvas の抽象平面では、島国／大陸の実験が「どの世界で起きているか」が伝わらず、見た目も弱い。観測コンソールとして世界地図で表現したい、という要求が出た。

## Decision

**空間可視化は Three.js の地球儀（世界地図）とする。**

| 要素 | 方針 |
|------|------|
| 地球 | 簡略化した大陸シルエットの手続きテクスチャ。写真地球は使わない（軽量・オフライン） |
| 舞台 | `geography` + `seed` で日本／イギリス／東南アジア、または東アジア／欧州／アフリカ／北米を選ぶ |
| 主体 | 地球上の点。色は集落と同一 |
| 操作 | ドラッグで回転、ホイールで拡大。再生中も可 |
| やらないこと | 建物モデル、リアル衛星写真、シネマティック演出 |

操作 UI は従来どおり PrimeVue。

## Consequences

良くなること

* 島国／大陸が実在の地理として読める
* 見た目が観測コンソールとして通りやすい

捨てること

* 抽象 0–100 平面をそのまま眺める単純さ
* Canvas 2D だけの軽量実装

後続

* 地形タイルの移動コストは、舞台上の緯度経度とは別にルール層で接続する
