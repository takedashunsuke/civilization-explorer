# 0002. 可視化は 2D 中心（地球画像・本格 3D は不要）

- Status: superseded
- Date: 2026-08-04
- Superseded by: [0005](./0005-threejs-world-globe.md)

## Context

観測 UI で「地球イラスト／本格 3D」が必要か検討した。  
チームは 3D 実装に慣れておらず、MVP の目的は文明の変化を直感的に眺めることであり、地球儀演出は必須ではない。

## Decision

**2D 中心で可視化する。地球の背景画像・グローブ演出は作らない。**

| 要素 | 方針 |
|------|------|
| 背景 | 抽象的な平面（薄いグリッド／単色〜穏やかなグラデーション）。地球写真・地球イラストは使わない |
| 世界マップ | **2D**（Canvas 2D または SVG）。Agent = 円、集落 = まとまり／簡易マーカー |
| UI 操作 | PrimeVue（従来どおり） |
| Three.js | MVP では必須にしない。必要なら後から **真上視点の 2.5D** に限定して追加可 |

画面は「PrimeVue の操作パネル ＋ 2D マップ」の組み合わせとする。

## Consequences

良くなること

* 実装・デバッグが簡単で、ハッカソン向き
* 「誰がどこにいて、どの集団か」が伝わりやすい
* 3D カメラ／ライティング／地球テクスチャの工数を避けられる

捨てること

* 地球儀やシネマティックな 3D 演出による見た目の派手さ
* README / 初期構想の「Three.js 前提」表現は「2D マップ（Three.js は任意）」に更新する
