# 0006. 観測の主画面は Natural Earth の平面地図

- Status: accepted
- Date: 2026-08-16
- Amends: [0005](./0005-threejs-world-globe.md)
- Related: [0002](./0002-2d-visualization.md)（抽象平面。世界地図ではない）

## Context

ADR 0005 で可視化を Three.js 地球儀にした。実在の地理は伝わるが、集団が領域を広げ、ぶつかり、都市・国家へ成長する過程は曲面だと読み取りにくい。観測の目的は「どの大陸か」だけでなく **集団の形成・衝突・拡大** である。

あわせて、3 カラム固定だと地図が狭い。初期条件と出来事は常時サイドバーである必要はない。

## Decision

**主画面は Canvas 2D の平面世界地図とする。地球儀は補助タブとして残す。**

| 要素 | 方針 |
|------|------|
| 既定ビュー | 平面地図。南極側下約 1 割は既定表示から外し、残りの範囲を画面に合わせる |
| 陸地 | Natural Earth のベクトル（簡略 JSON）。衛星写真は使わない（0005 を継承） |
| 陸の塗り | 気候帯ではなく標高。平野を明るく、高地を暗くする |
| 集団 | 所属色は HEX パレット。メンバーの凸包で領域、人数で集団／都市／国家ラベル |
| 衝突 | 当該ターンの集団間 `conflict` を破線で結ぶ |
| 地球儀 | 同一テクスチャの Three.js。タブで切替 |
| 初期条件 | 画面中央のモーダル。作成後は閉じ、ヘッダーから再表示 |
| 出来事 | 右下のチャット型パネル。表の固定サイドバーにはしない |
| ヘッダー指標 | 人口・富・幸福の抽象値ではなく、集団数・都市数・国家数・未所属・今ターンの争い／共同・特異の件数 |

都市は所属 8 人以上、国家は 20 人以上（観測用ラベル。ルール層の型ではない）。

## Consequences

良くなること

* 領域の広がりと衝突が平面で追える
* 地図を広く使える
* 「何人いるか／いくら持っているか」より、社会がどう分かれたかが読める

捨てること

* 地球儀を常時の主画面にすること
* 左右サイドバー常時表示

後続

* 侵略・吸収はルール層に専用行動がまだない。衝突線と領域の重なりで近似する
